# 薄肌比例导航 BodyNav

黑客松 demo：拍一张正面全身照，算出你现在的身材比例，和目标身材对比，告诉你差在哪块肌肉、每周训练组数怎么分。

在线 demo：https://anyali-1015.github.io/bodynav/

核心思路是**规则引擎决定结论，界面负责解释**。同样的输入永远得到同样的结果，每条结论都能在「规则轨迹」里查到是哪条规则、用哪个数算出来的。

## 怎么用

- 直接用浏览器打开 `index.html` 即可，不需要安装任何东西。
- 开页就有两个样例（A：窄肩 + 圆肩；B：臀部偏平 + 骨盆前倾），切换样例或目标身材，结论会跟着变。
- 「我的照片」：上传正面全身照，拖动 6 个点（肩外侧、腰最细处、臀最宽处）。照片只在浏览器本地处理，不会上传。
- 「自动识别关键点」：用 MediaPipe Pose 自动放置肩和臀的点。需要能联网加载模型；加载失败时会提示手动拖点。

## 测量了什么

| 指标 | 算法 |
|---|---|
| 肩腰比 | 两肩外侧距离 ÷ 腰最细处宽度 |
| 臀腰比 | 臀最宽处宽度 ÷ 腰最细处宽度 |
| 肩线倾斜 | 两肩高度差 ÷ 肩宽 |
| 髋线倾斜 | 两侧臀点高度差 ÷ 臀宽 |

2D 照片只能算相对比例，算不出绝对围度。圆肩、骨盆前倾需要侧面照判断，demo 中手动勾选。

## 规则表

### 预设模板（只比较比例）

| 规则 | 条件 | 结论 |
|---|---|---|
| R1a | 肩腰比差距 ≥ 0.10 | 三角肌中束 → 重点；背阔肌 → 加强 |
| R1b | 0.04 ≤ 肩腰比差距 < 0.10 | 三角肌中束、背阔肌 → 加强 |
| R2a | 臀腰比差距 ≥ 0.10 | 臀中肌、臀大肌 → 重点 |
| R2b | 0.04 ≤ 臀腰比差距 < 0.10 | 臀中肌、臀大肌 → 加强 |
| R7 | 目标为纤长芭蕾且臀腰比已达标 | 股四头肌 → 少分配（不是不练） |

差距 = 目标比例 − 当前比例。

### 我的目标（进阶生成 / 自定义 / 参考照片，按 cm 差距）

| 规则 | 条件 | 结论 |
|---|---|---|
| C1a | 肩宽差 ≥ 2.5 cm | 三角肌中束 → 重点；背阔肌 → 加强 |
| C1b | 0.5 ≤ 肩宽差 < 2.5 cm | 三角肌中束、背阔肌 → 加强 |
| C2a | 臀围差 ≥ 4 cm | 臀中肌、臀大肌 → 重点 |
| C2b | 1.5 ≤ 臀围差 < 4 cm | 臀中肌、臀大肌 → 加强 |
| C3a | 腿围差 ≥ 1.5 cm | 股四头肌、腘绳肌 → 加强 |
| C3b | 腿围比目标粗 ≥ 2 cm | 股四头肌 → 少分配 |
| C4 | 腰围比目标粗 ≥ 2 cm | 提示：腰围靠整体体脂下降，练腹不能局部瘦腰 |

差距 = 目标 − 当前（腰围是 当前 − 目标），取到 0.1 cm。

### 体态（两种目标都适用）

| 规则 | 条件 | 结论 |
|---|---|---|
| R3 | 圆肩 | 后束·中下斜方 → 重点；胸 → 少分配；加门框胸部拉伸 |
| R4 | 骨盆前倾 | 臀大肌、腘绳肌、核心 → 加强；加髋屈肌拉伸 |

每周默认 36 组左右，按 重点 3 : 加强 2 : 保持 1 : 少分配 0.5 的权重分配。

## 目标身材

### 预设模板（演示设定值）

| 目标 | 肩腰比 | 臀腰比 |
|---|---|---|
| 直角肩薄背 | 1.45 | 1.30 |
| 蜜桃线条 | 1.34 | 1.45 |
| 均衡薄肌 | 1.40 | 1.38 |
| 运动 X 型 | 1.50 | 1.45 |
| 纤长芭蕾 | 1.30 | 1.30 |

预设只看比例（腰围不变）。比例已经超过所有模板的人，用下面的「我的目标」继续精进。

### 我的目标

- **按身高和骨架生成（下一阶段）**：骨架上限 = 身高 × 系数 × 骨架系数（肩宽 0.25、臀围 0.60、腿围 0.34；骨架偏小 / 适中 / 偏大 = 0.96 / 1 / 1.04），理想腰围 ≈ 身高 × 0.40。选中的部位各往前走一个阶段（约 12 周：肩宽 +1、臀围 +2.5、腿围 +1.5、腰围 −3 cm），不超过上限；生成后固定，达成再生成下一阶段。
- **精细调整**：直接设定四项目标尺寸。
- **参考照片**：用和拍照扫描同一套点位提取肩腰比、臀腰比、腿臀比；全身照按你的身高换算，否则按你的腰围换算。超出你骨架上限、或要大幅减掉肌肉（超过两个阶段）的项按边界处理；比例超出常见人体范围时提示核对点位。

这些系数是演示用的经验值，正式版需要用真实样本校准。

# 薄肌比例导航 BodyNav

把「我想要直角肩 / 蜜桃臀」翻译成「这周练哪块肌肉、用哪几个动作」，打开就知道今天练什么。

在线：https://anyali-1015.github.io/bodynav/ （iPhone 用 Safari 打开 → 分享 → 添加到主屏幕）

## 怎么用

1. 首次打开做一次引导：性别、体型目标（最多 3 个）、每周去几次、练了多久、健身房里能用的器械。
2. 「训练」页：今天练哪些部位、动作明细（主练 / 基础）、整体跟练（摄像头自动计数 + 组间计时 + 语音）。
3. 器械被占：点「换」换成同肌群的其他动作，只对今天生效；在动作页可以设为以后都用。
4. 「周视图」：本周和上周每天练了哪些肌群（完成 / 跳过 / 休息 / 未到），以及接下来的训练顺序。
5. 「肌群」：3D 人体图谱，主练肌群高亮，点肌肉看作用、对体型的影响和对应动作。
6. 「我的 → 身体数据」可选：手动输入或拍照，只记录自己的变化，不和任何模板比较。

## 训练计划生成规则

计划由三个输入决定，同样的输入永远得到同样的计划。

### 体型目标 → 主练肌群

| 女 | 男 | 主练肌群 |
|---|---|---|
| 直角肩 | 宽肩 | 三角肌中束、三角肌后束 |
| 薄背 / 背部线条 | 倒三角背 | 背阔肌、后束 · 中下斜方 |
| 蜜桃臀 | — | 臀大肌、臀中肌 |
| — | 胸肌 | 胸大肌 |
| 腿部线条 | 腿臀力量 | 股四头肌、腘绳肌、臀大肌 |
| 腰线 | 腰腹线条 | 核心（腹横肌、腹斜肌），并提示训练不能局部减脂 |

没选的肌群也安排基础训练量（全身训练时 A / B 轮流），避免比例失衡。

### 每周次数 → 分化

| 每周 | 分化 | 主练肌群 |
|---|---|---|
| 2 次 | 全身 A / B | 每次 2 个动作，每周 2 次 |
| 3 次 | 全身 A / B / A 交替 | 每次 1 个动作，每周 3 次 |
| 4 次 | 上肢 / 下肢 / 上肢 / 下肢 | 每次 2 个动作，每周 2 次 |

### 训练经验 → 组数

| 经验 | 主练动作 | 其他动作 |
|---|---|---|
| 1–3 个月 | 3 组 | 2 组 |
| 3–6 个月 | 3 组 | 3 组 |
| 6–12 个月 | 4 组 | 3 组 |

### 排序、间隔与顺延

- 每次先复合动作、后孤立动作，主练肌群在前；单次最多 8 个动作。
- 同一主练肌群两次训练间隔至少 48 小时：昨天练过时，今天提示休息（可以选择仍然练）；本周次数练完也提示休息。
- 训练按顺序轮转，不绑定星期几。漏练或点「今天不练」，下次打开还是没完成的那一次，不会累积欠练。
- 没选的器械会换成同肌群的其他动作；自重动作不需要器械。
- 体态（可选）：圆肩加门框胸部拉伸，骨盆前倾加髋屈肌拉伸。

## 健康与安全

- 不出「差 X cm」之类的缺陷数字；身体数据只显示自己的变化。
- 选择腰线目标时说明训练不能局部减脂，偏瘦不建议以收腰为目标。
- 首次引导提示：有伤病或训练中疼痛，请先咨询医生或教练；每个动作标出受伤风险点。
- 计划是通用训练建议，不构成医疗或专业指导。

## 本地运行

```bash
python3 -m http.server 8000
```

纯静态单文件（`index.html`），无构建步骤。
